# Echo — Team Tracks and Ownership

The project was executed across two coordinated tracks:

## Track A — Core Memory Engine
- **Person 1 (Integration Lead)**: FastAPI setup, unified contracts (`CaseContext`, `AgentEvent`), WebSocket streaming, orchestration pipeline.
- **Person 2 (Hindsight / Memory Lead)**: Hindsight client, `support-experiences` memory bank, retain/recall/reflect lifecycle, fallback isolation.
- **Person 3 (Domain / Simulator Lead)**: 15 seeded historical experiences, 3 canonical hero cases, deterministic outcome simulator.

## Track B — Proof & Experience
- **Person 4 (Evaluation Lead)**: 8-case benchmark suite (`evaluation/benchmark_cases.json`), Memory OFF vs Memory ON comparisons, performance metrics calculations.
- **Person 5 (Frontend / UX Lead)**: React 18 dashboard, Live Case investigation visualizer, "What Changed My Mind?" comparison component.
- **Person 6 (Red Team / Deployment)**: Docker multi-stage configurations, Docker Compose orchestration, resilience testing against API dropouts.
